## The status vocabulary — use these three words only

| Status | Meaning |
|---|---|
| **Received** | The artefact exists, covers the period and answers the request |
| **Partial** | Something was provided, but it does not cover the period, the scope or the question. Say which |
| **Not available** | The evidence does not exist. **Say why in the same cell** — "never performed", "no register kept", "drafted, unapproved" |

> **The count is the finding.** A list where most rows read *Not available* is not an administrative problem; it is the
> readiness result. Report the three counts in the summary, and keep the reasons — they become the evidence-capture plan.

## Fill-in checklist

- [ ] Every request names **one** artefact. "Access documentation" is not a request; "the Q1 privileged access review record, signed and dated" is.
- [ ] Every row has a job-title owner and a due date.
- [ ] Every row says which workpaper or criterion it feeds, so nothing is requested that nobody will test.
- [ ] Each status uses the three words above, and every *Not available* carries its reason.
- [ ] The three counts (received / partial / not available) are reported with the readiness score.
- [ ] Evidence that does not exist is recorded as missing — never re-described as something else that does exist.
